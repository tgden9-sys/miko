# MIKO game

**Art direction:** Anime first, with cyberpunk details in support. The current industrial city is a mechanics sandbox rather than the final visual target. New environment art should favour expressive silhouettes, hand-painted texture, warm variation, and clear colour states. See `../Game Ideas/README.md`.

This is the active Godot project. Open `project.godot` and press F5.
To watch MIKO's platform attachment and polarity launch loop, double-click `../Play MIKO Charge Platform Preview.cmd`. The same animation and physics run in the industrial city test level.
See `../Docs/CURRENT_STATE.md`, `../Docs/CONTROLS.md` and `../Docs/BUILD.md`.
Older readmes and delivery notes are in `../Archive/Docs`.
