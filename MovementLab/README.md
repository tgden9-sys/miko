# MIKO Movement Lab

Open `project.godot` in Godot 4.7.2 or use **Play Movement Lab.cmd** in the parent folder. This is the standalone movement/combat rework, not the existing game.

Controller: A jump, X attack, B dash, LB parry. Up + X launches; down + X in air slams. Y toggles dummy attacks, View resets, R3 toggles close view.

Keyboard: A/D, Space, J, Shift, K; W/S attack direction. T dummy, R reset, Z view.

The detailed decisions, timings, sources and validation are in `../Docs/MOVEMENT_LAB.md`.
