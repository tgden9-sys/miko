# Shelved service pedestal study

`original.glb` is the supplied Trellis mesh. Run `build_service_pedestal.py` with
Blender in background mode to rebuild the runtime GLB. The script keeps the
painted enclosure and its pipe, clears the reconstructed socket, and replaces
the insert with a collar, a recessed gasket, and copper contact blocks.

The isolated Godot scene is a rejected art study. No playable level instances
it. Its geometry and placement do not define the section completion mechanic.
