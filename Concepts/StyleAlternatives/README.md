# Alternative environment styles

Exploratory comparison concept, generated with built-in image generation. Not an actual Godot render or a guarantee of runtime quality. Current painted scenery development is paused pending direction.

A: clean cel-shaded 3D. B: cinematic industrial PBR. C: graphic simplified sci-fi. D: miniature diorama.

All require deliberate modelling and lighting to reproduce in-game. A and C can use simpler geometry and selective detail. B and D depend more heavily on detailed geometry and material work. A generated comparison alone does not establish laptop performance; any selected direction should first be proven on a single real six-metre game section.

The main backdrop trial has been placed using existing left/centre/right artwork. It is not a final connected background library; long-section joins still require authored transitions. Do not repeat the failed narrow image-strip cover experiment.
