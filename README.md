# MIKO — main game workspace

This is the working home for the main game, starting from the approved v30 build.

**Play:** double-click **Play MIKO.cmd**. **Edit:** double-click **Open MIKO Editor.cmd**,
or import `Game/project.godot` in Godot. Current engine: Godot 4.7.2.

| Folder | Purpose |
|---|---|
| `Game` | Active Godot project; make game changes here |
| `Source/Character` | Editable Blender master, inputs and character export scripts |
| `Docs` | Current project state, controls and build instructions |
| `Builds` | Future exported game builds and validation results |
| `Previews` | Recent approved motion previews |
| `Archive` | Earlier notes and preserved milestone ZIPs |

Start with [the current state](Docs/CURRENT_STATE.md) and [controls](Docs/CONTROLS.md).
Historical documentation is archived and may describe superseded behaviour.
The original prototype workspace remains available as a rollback copy.
